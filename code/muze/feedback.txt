# qtipps:

So I've played around with a good bit and I think that aside from the scancodes thing, which is complicating matters a good deal, those quality of life things mixer brought up are definitely worth addressing.

- The thing that's worth noting is that I do think this program could be really good for some people if you really figure out how to make this an easy, intuitive automatic transcription or practice tool. Either way there are some shared priorities that need to be handled first, and I'd break it down like this:
- The program needs to be able to handle time signatures. You could also keep the present free time feel, but if that's the case the user needs to be able to put a bar wherever they feel like to communicate phrasing. I've done a lot of work in the sacred music space and it's a real pain if the notation software forces me to a grid for chant.
The program needs to be able to handle Key signatures. This isn't useful to people who don't read music, and people who read music need key signatures for basic sanity.
- Since this works only with midi instruments at the moment this is pretty keyboard focused but there are electric sax/wind instruments out there that might be useful. Some guitar players might have a midi output on their rig, but we can pretty much ignore everything but keys for now. That means you probably need to be able to handle chords, multiple voicings, and at least a bass and treble clef. I don't know if it's worth considering the possibility of organ pedals, but don't box yourself in.

A the composition route:
Double check and make sure this has options to edit any note manually after it's transcribed.

- I really like the idea of this being able to transcribe what I'm playing in real time, but that does require that it be able to interpret separate hands and (probably) have an auto-pause feature. Finale was always terrible at this and I don't know that I had much luck with muse score either.
   a. To clarify the auto-pause thing, stop adding more empty lines if we've already added one full measure of rests

- If you get that auto-transcription thing down pat, you've got yourself a customer base, say $40 or so. It'd be more but Tantacrul is good at what he does and what he does is make MuseScore free. Make sure this can export to more fully-featured programs until most people don't have a reason to want to edit a file in MuseScore or Sibelius. I have pages of notes scribbled for tunes that I leave unfinished in museScore because I get distracted trying to input notes I'd rather just play.

B. The practice route:
- If you get it so this shows sheet music in a way the user can read it, you've already got a decent idea for a tool, but from a musician's standpoint, rhythm is king. It's nice if someone hits a right note, especially the bass player. If someone hits a note off beat everyone is screwed. This is especially true of the bass player. The way this currently works encourages players to focus on notes over rhythm. For classical stuff you can sometimes get away with that on a busy piece, but try it on Mozart and you'll be hanged.
- The same way that the composition side needs a transcription engine to be able to save the composer time, the practice side needs to be able to interpret rhythmic interpretation as such and also know when someone needs to have a cymbal thrown at their head. If someone is consistent in where the downbeats and upbeats come and they keep a steady tempo, they're correct as far as the machine can tell. If you can do that I'll be your first customer. Maybe let the user set tolerances on this with a slider.
  a. this gets tricky if the eighths/quavers are swung.

- For Practice mode, I should be able to set a target tempo and a current tempo. Start the user where they want, and then any time they screw up, slow them down by half until they get to 60bpm, at which point you can take off 10bpm. If they dip below 40bpm I don't know what to do aside from issuing Hail Marys and Our Fathers. If they play it right X times in a row (user determined), give them another 10 bpm on the metronome until they hit their target. This is basically how I was taught to practice, and you've written the first bit of tooling that I think could help with it.

- Sorry for the rant, but I'd drop $20 today for something to automatically adjust my metronome settings when I'm doing exercises, scales, and arpeggios. For those you don't even need all of the notation stuff worked out. I know that's not exactly a princely sum but if you get enough of the transcription stuff right as well and you only need to worry about pricing to keep people from finding out a way to do it in muse score.
